# Diagonal Studios — Sitio Web

Repositorio del sitio web y landing page oficial de **Diagonal Studios**, un estudio de desarrollo de software enfocado en la creación de productos digitales y soluciones integrales de punta a punta.

## Sobre Diagonal Studios

Diagonal Studios desarrolla soluciones de software para empresas, emprendimientos, startups y organizaciones de cualquier tamaño.

Nuestros servicios incluyen:

* Sitios web
* Aplicaciones web
* Aplicaciones móviles
* Sistemas a medida
* E-commerce
* Productos SaaS
* Soluciones digitales integrales

## Tecnologías

* [Astro](https://astro.build/)
* [TypeScript](https://www.typescriptlang.org/)
* [Tailwind CSS](https://tailwindcss.com/)

## Desarrollo

Cloná el repositorio e instalá las dependencias:

```bash
git clone <repository-url>
cd website
npm install
```

Iniciá el servidor de desarrollo:

```bash
npm run dev
```

El sitio estará disponible en la URL local proporcionada por Astro.

Para generar el build de producción:

```bash
npm run build
```

Para previsualizar el build de producción localmente:

```bash
npm run preview
```
